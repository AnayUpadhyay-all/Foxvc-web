Core Architecture

What Makes FoxVC Different

Built from first principles to be small, self-contained, and predictable.

📏

Exact 25-Keyword Lexicon

No unexpected aliases or duplicate keywords. Strict boolean values (aye, nay, blank) and logical operators (also, either, deny) keep code predictable across machines.

🗄️

Native SQLite Persistence

Embedded relational database functionality is built into the standard library shelf. Open connections, run parameterized queries, and persist structured data without installing external packages.

⚡

~14 KB Standalone C VM

The core virtual machine (engine/foxvm.c) compiles into a compact binary linking only libc and libm. Includes a tiered memory arena allocator and tail-call optimization.

🎮

Built-in Raylib 2D Graphics

Hardware-accelerated 2D windowing, shape drawing, and keyboard/mouse input bindings are part of the standard graphics shelf, enabling rapid prototyping of visual tools and games.

🌐

Decoupled Web Model

FoxVC explores a decoupled three-layer web concept: semantic structure in .fweb, visual appearance rules in .fskin, and reactive client behavior in .flogic.

📱

Mobile & Offline Friendly

Runs offline on Linux, macOS, Windows, and directly on Android via Termux with native ARM64 compilation support and a touch-friendly local studio.

Why I Created FoxVC

I started FoxVC on September 2, 2026 as an offline engineering experiment. I wanted a language where every keyword has a singular meaning, with zero syntax collision with mainstream languages, and a small runtime that can compile into a single standalone binary.

Most modern languages come with 40+ keywords, complex runtime runaways, and heavy package dependencies just to do basic local SQLite operations or open a 2D window. FoxVC keeps things compact: 25 keywords, built-in SQLite persistence, Raylib graphics, and a fast 14 KB C virtual machine.

On October 10, 2026, FoxVC was open-sourced on GitHub under the MIT License. Today it continues to grow as an independent project with automated testing, LSP support, and multi-platform compilation.
