Architecture

Engineered Without External Bloat

Designed from first principles to be small, self-contained, and predictable.

📏

Exact 25-Keyword Lexicon

No competing synonym aliases or ambiguous grammar branches. Strict boolean values (aye, nay, blank) and logical operators (also, either, deny) keep code predictable.

🗄️

Native Embedded SQLite

Embedded relational database functionality is built directly into the standard runtime shelf. Open connections, run parameterized queries, and persist data without installing external packages.

⚡

~14 KB Standalone C VM

The core virtual machine (engine/foxvm.c) compiles into a compact standalone binary linking only libc and libm. Includes a tiered memory arena allocator and tail-call optimization.

🎮

Raylib 2D Hardware Graphics

Hardware-accelerated windowing, sprite rendering, geometry drawing, and keyboard/mouse input bindings are built right into the standard graphics shelf.

🌐

Decoupled Web Architecture

FoxVC explores a decoupled three-layer web concept: semantic structure in .fweb, visual appearance rules in .fskin, and reactive client behavior in .flogic.

📱

Cross-Platform & Offline

Runs offline on Linux, macOS, Windows, and directly on Android via Termux with native ARM64 compilation support and a touch-friendly local studio.

Why I Created FoxVC

I started FoxVC on September 2, 2026 as an offline engineering project. I wanted a language where every keyword has a singular meaning, with zero syntax collision with mainstream languages, and a small runtime that can compile into a single standalone binary.

Most modern languages come with 40+ keywords, runtime bloat, and heavy package dependencies just to do basic local SQLite operations or open a 2D window. FoxVC keeps things compact: 25 keywords, built-in SQLite persistence, Raylib graphics, and a fast 14 KB C virtual machine.

On October 10, 2026, FoxVC was open-sourced on GitHub under the MIT License. Today it continues to grow as an independent project with automated testing, LSP support, and multi-platform compilation.
