---

## ⚡ Features

- **🚀 Interactive In-Browser Playground:** Run simulated FoxVC programs directly in the browser (Fibonacci Tail-Call Optimization, SQLite persistence, Decoupled Web Model, Raylib 2D, and AI Agent Orchestration).
- **🎨 Ultra-Premium Cyberpunk Glassmorphism:** High-end dark mode aesthetics, dynamic particle mesh canvas, glowing neon accents, and interactive card hovers.
- **📢 Social Ad Deck & Virality Cards:** Pre-formatted promotional cards optimized for sharing on Twitter/X, Hacker News, Reddit, and Product Hunt.
- **📊 Real Benchmark Visualizations:** Animated performance comparisons between FoxCVM, C, Node.js, and Python.
- **▲ Zero-Config Vercel Deployment:** Pre-configured with `vercel.json` for edge caching, clean URLs, and maximum performance.

## 🚀 Instant Vercel Deployment

### Method 1: 1-Click Deploy Button
Click the button below to deploy this repository to your Vercel account instantly:

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/AnayUpadhyay-all/Foxvc-web)

### Method 2: Vercel CLI
```bash
# Install Vercel CLI if not already installed
npm i -g vercel

# Deploy directly from this directory
cd Foxvc-web
vercel
```

### Method 3: Connect via Vercel Dashboard
1. Go to [vercel.com/new](https://vercel.com/new).
2. Select and import **`AnayUpadhyay-all/Foxvc-web`**.
3. Leave default settings (Framework Preset: Other / Static).
4. Click **Deploy**.

## 💻 Local Development & Preview

Run locally using any static file server:

```bash
# Using Python
python3 -m http.server 3000

# Using Node.js
npx serve .
```

Open `http://localhost:3000` in your browser.
